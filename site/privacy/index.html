Privacy, in plain language.

Your document contents stay on your computer. The desktop app has no analytics, ads, account system, or cloud document storage.

What the app stores

The app stores folder paths, snapshots, preview text, capture times, and file hashes in its application data directory.

The app does not send this archive to Document History Bridge or Param Factory.

License checks

If you enter an Archive license, the app sends its token and product name to the Sociobot billing API.

The app stores the token and its latest check on your computer.

Website and demo

The website asks GitHub for current release metadata. Installer links then open GitHub Releases.

The browser demo uses sample files and a local key beginning with demo:. Resetting or leaving for download removes that key.

The website has no analytics, tracking pixels, ads, or third-party fonts.

Payments

Sociobot and Dodo handle checkout as the merchant of record. This site does not receive your card details.

Delete local data

Remove watched folders in the app. Then delete its application data directory to erase the archive.

Uninstalling may preserve that directory so accidental removal does not erase your history.

Contact

Open an issue in the public source repository with privacy questions.

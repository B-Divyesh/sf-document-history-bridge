Clear limits

Know what the preview cannot read.

Encrypted, damaged, and image-only files do not get a text preview. The app still keeps each supported file snapshot.

  • Works while the desktop app runs
  • Reads text layers but does not run OCR
  • Does not sync or edit with other people
  • Needs a separate backup for device loss
